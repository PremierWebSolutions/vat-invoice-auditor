# Reference catalog

One card per source provision. Read this catalog, then open **only** the card(s) the audit at hand needs — never load the whole folder.

| Card | File | What it answers |
|---|---|---|
| reg 13 | [vat-regulations-1995-reg-13.md](vat-regulations-1995-reg-13.md) | Who must issue a VAT invoice, and when one is required at all (incl. self-billing conditions) |
| reg 14 | [vat-regulations-1995-reg-14.md](vat-regulations-1995-reg-14.md) | The particulars a **full** VAT invoice must state — the main checklist, reg 14(1)(a)–(p) |
| reg 16 | [vat-regulations-1995-reg-16.md](vat-regulations-1995-reg-16.md) | **Retailers'** invoices: the £250 relaxation and the ban on exempt supplies |
| reg 16A | [vat-regulations-1995-reg-16A.md](vat-regulations-1995-reg-16A.md) | **Simplified** invoices (non-retailers): the £250 relaxation |
| Notice 700/21 §§3–4 | [vat-notice-700-21-invoicing.md](vat-notice-700-21-invoicing.md) | HMRC's operational reading: the 30-day issue rule, the full checklist in plain words (4.1), retailer and simplified options (4.4–4.5), when no invoice is needed (4.6) |

Typical loads:

- Auditing a **full VAT invoice** → reg 14 + Notice §4.1.
- Auditing a **simplified or retailer invoice** → reg 16A (or reg 16 if the issuer is a retailer) + Notice §§4.4–4.5.
- Question is *whether an invoice was required at all* → reg 13 + Notice §4.6.

The severity classification and citation format live in [rules.md](../rules.md), not here.
